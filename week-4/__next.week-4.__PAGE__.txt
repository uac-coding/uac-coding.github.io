## Operators

Operators are special symbols or keywords used to perform computations, comparisons, and logic evaluations on values and variables.

### Relational Operators

Relational operators compare how two variables or values relate to each other. They always evaluate to a boolean value of either True or False.

| Operator | Name | Explanation | Example | Result |
| :--- | :--- | :--- | :--- | :--- |
| `==` | Equal to | Checks if two values are identical to each other. | `5 == 5` | `True` |
| `!=` | Not equal | Checks if two values are different from each other. | `5 != 3` | `True` |
| `>` | Greater than | Checks if the value on the left is strictly larger than the right. | `5 > 3` | `True` |
| `<` | Less than | Checks if the value on the left is strictly smaller than the right. | `3 < 5` | `True` |
| `>=` | Greater or equal | Checks if the left value is larger than or equal to the right. | `5 >= 5` | `True` |
| `<=` | Less or equal | Checks if the left value is smaller than or equal to the right. | `3 <= 5` | `True` |

```python copy
print(5 == 5)  # True
print(5 != 3)  # True
print(5 > 3)   # True
print(5 < 3)   # False
```

### Logical Operators

Logical operators allow you to combine multiple True or False conditions to make complex decisions.

| Operator | Name | Explanation | Example | Result |
| :--- | :--- | :--- | :--- | :--- |
| `and` | Logical AND | Evaluates to True only if both conditions are True at the same time. | `True and False` | `False` |
| `or` | Logical OR | Evaluates to True if at least one of the conditions is True. | `True or False` | `True` |
| `not` | Logical NOT | Reverses the boolean outcome, turning True to False and vice versa. | `not True` | `False` |

#### Example using AND

```python copy
grade = 6

if grade >= 6 and grade <= 12:
    print("You can join the club!")
else:
    print("Sorry, you cannot join.")
```

#### Example using OR

```python copy
age = 18

if age < 12 or age > 65:
    print("You get the discount!")
else:
    print("Regular price.")
```

## Conditionals

Conditionals let your program branch and execute different blocks of code depending on whether specific conditions are met. Instead of running every line in order, the computer checks questions and chooses a path.

| Keyword | Name | Explanation | Example |
| :--- | :--- | :--- | :--- |
| `if` | If Statement | The starting check. If the condition is True, its indented code block runs. | `if temperature > 25:` |
| `elif` | Else If Statement | A secondary check evaluated only if the preceding conditions were False. | `elif temperature > 10:` |
| `else` | Else Statement | A catch all default block that runs when all previous conditions fail. | `else:` |

### Example: What should I wear today?

```python copy
temperature = 15

if temperature > 25:
    print("Wear a shirt")
elif temperature > 10:
    print("Wear a light jacket")
else:
    print("Wear a heavy jacket")
```
