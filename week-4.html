Week 4

Week Four

This week we learn about operators and conditionals. You will discover how to compare values and make decisions in your program based on True or False answers.

Presentation

Operators

Operators are special symbols or keywords used to perform computations, comparisons, and logic evaluations on values and variables.

Relational Operators

Relational operators compare how two variables or values relate to each other. They always evaluate to a boolean value of either True or False.

OperatorNameExplanationExampleResult
==Equal toChecks if two values are identical to each other.5 == 5True
!=Not equalChecks if two values are different from each other.5 != 3True
>Greater thanChecks if the value on the left is strictly larger than the right.5 > 3True
<Less thanChecks if the value on the left is strictly smaller than the right.3 < 5True
>=Greater or equalChecks if the left value is larger than or equal to the right.5 >= 5True
<=Less or equalChecks if the left value is smaller than or equal to the right.3 <= 5True
print(5 == 5)  # True
print(5 != 3)  # True
print(5 > 3)   # True
print(5 < 3)   # False

Logical Operators

Logical operators allow you to combine multiple True or False conditions to make complex decisions.

OperatorNameExplanationExampleResult
andLogical ANDEvaluates to True only if both conditions are True at the same time.True and FalseFalse
orLogical OREvaluates to True if at least one of the conditions is True.True or FalseTrue
notLogical NOTReverses the boolean outcome, turning True to False and vice versa.not TrueFalse

Example using AND

grade = 6
 
if grade >= 6 and grade <= 12:
    print("You can join the club!")
else:
    print("Sorry, you cannot join.")

Example using OR

age = 18
 
if age < 12 or age > 65:
    print("You get the discount!")
else:
    print("Regular price.")

Conditionals

Conditionals let your program branch and execute different blocks of code depending on whether specific conditions are met. Instead of running every line in order, the computer checks questions and chooses a path.

KeywordNameExplanationExample
ifIf StatementThe starting check. If the condition is True, its indented code block runs.if temperature > 25:
elifElse If StatementA secondary check evaluated only if the preceding conditions were False.elif temperature > 10:
elseElse StatementA catch all default block that runs when all previous conditions fail.else:

Example: What should I wear today?

temperature = 15
 
if temperature > 25:
    print("Wear a shirt")
elif temperature > 10:
    print("Wear a light jacket")
else:
    print("Wear a heavy jacket")

Challenges

The Church Volunteer Age Checker

Write a Python program that asks the user for their age using input, typecasts it to an integer, and uses an if statement to check if they are old enough to help in the media ministry.

Requirements:

  1. Prompt the user for their age.
  2. Typecasts the input into an integer.
  3. Use an if or else statement to check if the user is 16 or older.

Expected Output (if user types 17):

Enter your age: 17
You are cleared to join the media ministry team!

View Solution

# Media ministry volunteer age checker
age_str = input("Enter your age: ")
age = int(age_str)
 
if age >= 16:
    print("You are cleared to join the media ministry team!")
else:
    print("Thank you for your interest! You can join when you turn 16.")

The Church Ministry Grade Placement

Write a program that uses conditionals and relational operators to sort students into the correct church ministry based on their school grade (Children’s Ministry for up to grade 5, Extension for grade 6, and In Service for older than grade 6).

Requirements:

  1. Prompt the user for their school grade (typecasted to an integer).
  2. Use if, elif, and else statements to assign them to Children’s Ministry, Extension, or In Service.

Expected Output (if user types 6):

Enter your school grade: 6
Placement: Extension Program

View Solution

# Church ministry grade placement
grade_str = input("Enter your school grade: ")
grade = int(grade_str)
 
if grade <= 5:
    print("Placement: Children's Ministry")
elif grade == 6:
    print("Placement: Extension Program")
else:
    print("Placement: In Service")

The Church Event Budget Tier Classifier

Write an advanced script that prompts the user for a church youth camp registration count and uses if, elif, and else statements to determine the event venue tier and bus requirements.

Requirements:

  1. Prompt the user for the number of camp attendees (typecasted to an integer).
  2. If attendees are less than 50, assign ” Chapel Hall and 1 Mini Bus”.
  3. If attendees are between 50 and 150 inclusive, assign ” Main Sanctuary and 2 Coaches”.
  4. Otherwise, assign ” Conference Center and Full Fleet”.

Expected Output (if user types 85):

Enter camp attendee count: 85
Assigned Venue and Transport: Main Sanctuary and 2 Coaches
