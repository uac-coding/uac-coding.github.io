## Variables

Variables are **containers that store information**. You give them a name and assign a value using `=`.

```python copy
world = '🌎🌍🌏'
python = 'Python 🐍'
fire = '🔥'
name = 'Shirley'
```

- `world` stores emojis.  
- `python` stores text with an emoji.  
- `fire` stores a fire emoji.  
- `name` stores a string representing a name.  

💡 Tip: Variables can store **text (strings)**, **numbers**, or other types of data.

### More Examples

```python copy
name = "Alice"
age = 12
is_student = True
print(f"{name} {age}")
```

### Changing Variable Values

You can update a variable by assigning it a new value:

```python copy
score = 0
score = 10
print(score)  # 10
```

### Using Variables in f-strings

f-strings let you insert variables directly into text:

```python copy
name = "Alex"
print(f"Hello, {name}!")
```

This prints:
```
Hello, Alex!
```

## Print / Output

`print()` shows information on the screen. It's how you check what your code is doing.

```python copy
print("This is output!")
```
