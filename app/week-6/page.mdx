## Loops

A **loop** tells a computer to repeat a block of code until a specific stopping condition is met. 

Instead of writing repetitive commands line by line:
```python copy
print("Clap")
print("Clap")
print("Clap")
print("Clap")
```

We can use a loop to make our code shorter, cleaner, and less prone to errors!

---

### For Loop

A **`for` loop** repeats a block of code once for every item in a list. Once it reaches the end of the list, the loop stops automatically.

```python copy
fruits = ["apple", "banana", "cherry"]

for fruit in fruits:
    print(fruit)

print("Finished")
```

**How it works:**
1. Python takes the first item (`"apple"`) and assigns it to the variable `fruit`, then prints it.
2. It moves to `"banana"`, updates `fruit`, and prints it.
3. It moves to `"cherry"`, updates `fruit`, and prints it.
4. Since no items remain, Python exits the loop and moves to the next line (`print("Finished")`).

💡 **Important:** Remember to indent the lines of code inside your loop!

---

### While Loop

A **`while` loop** continues to execute statements as long as its condition remains `True`.

```python copy
timer = 3

while timer > 0:
    print(timer)
    timer = timer - 1

print("Blast off!")
```

**How it works:**
1. `timer` starts at `3`.
2. Python checks if `timer > 0`. Since `3 > 0` is `True`, it prints `3` and updates `timer` to `2`.
3. It checks `2 > 0` (`True`), prints `2`, and updates `timer` to `1`.
4. It checks `1 > 0` (`True`), prints `1`, and updates `timer` to `0`.
5. Now `0 > 0` is `False`, so Python exits the loop and prints `"Blast off!"`.

⚠️ **Beware of Infinite Loops:** If you forget to change the variable inside a `while` loop (like omitting `timer = timer - 1`), the condition will stay `True` forever and your program will crash!

        ### Jericho March Countdown
        The Bible records that God commanded Joshua and the Israelites to march around the walls of Jericho once a day for six days, and seven times on the seventh day before the walls fell.

        Write a Python program using a `while` loop that counts down the remaining marching laps starting from 7 down to 1, and then prints a shouting message.

        **Requirements:**
        1. Initialize a variable `laps = 7`.
        2. Use a `while` loop that runs while `laps > 0`.
        3. Print `"Lap..."` along with the current lap number.
        4. Decrement `laps` by `1` during each iteration.
        5. After the loop, print `"Shout! The walls of Jericho have fallen!"`.

        **Expected Output:**
        ```text
        Lap 7 complete!
        Lap 6 complete!
        Lap 5 complete!
        Lap 4 complete!
        Lap 3 complete!
        Lap 2 complete!
        Lap 1 complete!
        Shout! The walls of Jericho have fallen!
        ```

        <details>
        <summary><b>View Solution</b></summary>

        ```python copy
        # Jericho March Countdown
        laps = 7

        while laps > 0:
            print(f"Lap {laps} complete!")
            laps = laps - 1

        print("Shout! The walls of Jericho have fallen!")
        ```

        ### Feeding of the 5,000 Basket Distributor
        Write a Python program that simulates distributing 5 loaves of bread to a crowd. Using a `while` loop, ask the user how many loaves they want to hand out until all loaves are gone.

        **Requirements:**
        1. Start with `loaves = 5`.
        2. Use a `while` loop that runs as long as `loaves > 0`.
        3. Display the remaining number of loaves.
        4. Prompt the user with `input()` asking how many loaves to give out.
        5. Subtract that number from `loaves`.
        6. When `loaves` reaches `0` (or fewer), exit the loop and print `"All loaves distributed!"`.

        **Expected Output (example user interaction):**
        ```text
        Loaves remaining: 5
        How many loaves to give out? 2
        Loaves remaining: 3
        How many loaves to give out? 3
        All loaves distributed!
        ```

        <details>
        <summary><b>View Solution</b></summary>

        ```python copy
        # Feeding of the 5,000 Basket Distributor
        loaves = 5

        while loaves > 0:
            print(f"Loaves remaining: {loaves}")
            given = int(input("How many loaves to give out? "))
            loaves = loaves - given

        print("All loaves distributed!")
        ```
