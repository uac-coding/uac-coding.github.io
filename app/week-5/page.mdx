## Lists

A **list** stores many values inside a single variable. Real-life examples of lists include a shopping list or a list of tasks.

In Python, lists are created using square brackets `[]` with items separated by commas:

```python copy
fruits = ["apple", "banana", "cherry"]
numbers = [1, 2, 3, 4, 5]
mixed = ["Alex", 12, True]
```

---

### Index

Each item in a list has a position number called an **index**. 

💡 **Important:** Indexes start at `0`!

| Index | Item |
| :--- | :--- |
| `0` | `"apple"` |
| `1` | `"banana"` |
| `2` | `"cherry"` |

```python copy
fruits = ["apple", "banana", "cherry"]

print(fruits[0])  # Output: apple
print(fruits[1])  # Output: banana
print(fruits[2])  # Output: cherry
```

---

### Length

Use `len()` to get the total number of items in a list.

```python copy
fruits = ["apple", "banana", "cherry"]
print(len(fruits))  # Output: 3
```

---

### Append

Use `.append()` to add a new item to the **end** of a list.

```python copy
fruits = ["apple", "banana"]
fruits.append("cherry")
print(fruits)  # Output: ['apple', 'banana', 'cherry']
```

---

### Remove

Use `.remove()` to remove a specific item from a list.

```python copy
fruits = ["apple", "banana", "cherry"]
fruits.remove("banana")
print(fruits)  # Output: ['apple', 'cherry']
```

        ### Torah Books List Inspector
        The **Torah** (meaning "instruction" or "teaching") refers to the first five books of the Bible, also known as the Law or the Five Books of Moses. 

        | Book | Theme |
        | :--- | :--- |
        | Genesis | Creation, early history, and God's covenant with the patriarchs. |
        | Exodus | Liberation from Egypt, the Ten Commandments, and the Tabernacle. |
        | Leviticus | Laws, holy living, and worship instructions. |
        | Numbers | The 40-year journey of Israel wandering in the wilderness. |
        | Deuteronomy | Moses' final speeches reviewing the Law before entering the Promised Land. |

        Write a Python program that creates a list of the 5 books of the Torah, prints the first item (at index 0), and then prints the total number of items in the list.

        1. Create a list called `torah_books` with the 5 books of the Torah: `"Genesis"`, `"Exodus"`, `"Leviticus"`, `"Numbers"`, and `"Deuteronomy"`.

        3. Print the total count of books using `len()`.

        **Expected Output:**
        ```text
        First book of the Torah: Genesis
        Total books in the Torah: 5
        ```

        ```python copy
        print(f"Total books in the Torah: {len(torah_books)}")
        ```

        ### Sunday School Attendance Tracker
        Write a Python program that starts with a list of Sunday school students. The user will be prompted to enter a new student's name, which will be added to the list using `.append()`. Finally, display the updated list and total student count.

        **Requirements:**
        1. Create a starting list of students: `["Daniel", "Esther", "Samuel"]`.
        2. Prompt the user to enter a new student name using `input()`.
        3. Add the new student to the end of the list using `.append()`.
        4. Print the updated list and total count using `len()`.

        **Expected Output (if user types "Ruth"):**
        ```text
        Enter new student name: Ruth
        Updated Students: ['Daniel', 'Esther', 'Samuel', 'Ruth']
        Total Students: 4
        ```

        <details>
        <summary><b>View Solution</b></summary>

        ```python copy
        # Sunday school attendance tracker
        students = ["Daniel", "Esther", "Samuel"]

        new_student = input("Enter new student name: ")
        students.append(new_student)

        print(f"Updated Students: {students}")
        print(f"Total Students: {len(students)}")
        ```

        ### Church Outreach Prayer Request Manager
        Write an advanced script that manages a list of prayer requests. The program displays the current prayer items, lets the user choose an item to remove (once answered), adds a new prayer request, and prints out the finalized list.

        **Requirements:**
        1. Start with a prayer request list: `["Healing for John", "Travel safety for Sarah", "Provision for family", "Wisdom for leaders"]`.
        2. Prompt the user to enter a prayer request to remove (e.g., when answered).
        3. Remove that item from the list using `.remove()`.
        4. Prompt the user to enter a new prayer request to add.
        5. Append the new prayer request to the list.
        6. Print the finalized prayer list and its total item count.

        **Expected Output (if user removes "Provision for family" and adds "Peace for community"):**
        ```text
        Current Prayer Requests: ['Healing for John', 'Travel safety for Sarah', 'Provision for family', 'Wisdom for leaders']
        Enter answered prayer to remove: Provision for family
        Enter new prayer request: Peace for community
        Final Prayer List: ['Healing for John', 'Travel safety for Sarah', 'Wisdom for leaders', 'Peace for community']
        Total active prayer requests: 4
        ```

        <details>
        <summary><b>View Solution</b></summary>

        ```python copy 
        # Church Outreach Prayer Request Manager

        prayer_requests = [
            "Healing for John",
            "Travel safety for Sarah",
            "Provision for family",
            "Wisdom for leaders"
        ]

        print(f"Current Prayer Requests: {prayer_requests}")

        answered_prayer = input("Enter answered prayer to remove: ")
        prayer_requests.remove(answered_prayer)

        new_prayer = input("Enter new prayer request: ")
        prayer_requests.append(new_prayer)

        print(f"Final Prayer List: {prayer_requests}")
        print(f"Total active prayer requests: {len(prayer_requests)}")
        ```
