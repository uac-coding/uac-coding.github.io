## Instructions / Commands

Code is a set of instructions for the computer to follow. Each instruction tells the computer to do **one thing** at a time.

```python copy
print("Hello world")  # This tells the computer to show text
```

## Data Types

Different kinds of information are stored differently in Python:

- **Strings** = text `"Hello"`  
- **Numbers** = integers or decimals `5`, `3.14`  
- **Booleans** = True/False `True`

```python copy
message = "Hi there!"
count = 5
is_happy = True
```

### Strings

Strings hold text. You can use single or double quotes.

```python copy
name = "Alice"
greeting = 'Hello!'
emoji = "🐍"
```

### Numbers

Python has two main number types:

- **Integers** (`int`) — whole numbers like `5`, `10`, `-3`
- **Floats** (`float`) — decimal numbers like `3.14`, `2.5`

```python copy
age = 12
price = 9.99
```

### Booleans

Booleans represent **True** or **False**. They are used when making decisions in code.

```python copy
is_raining = False
can_join = True
```

## Checking a Value's Type

Use `type()` to see what kind of data something is:

```python copy
print(type("Hello"))  # <class 'str'>
print(type(42))       # <class 'int'>
print(type(3.14))     # <class 'float'>
print(type(True))     # <class 'bool'>
```

## Comments

Comments are notes for humans. The computer ignores them. In Python, start a comment with `#`.

```python copy
# This is a comment
print("Hello")  # This prints Hello
```

## Order Matters

Computers follow instructions **line by line**, top to bottom. The order of your code affects the result.

```python copy
print("First line")
print("Second line")
```
