Week Three

This week we learn about variables — containers that store information so you can use it later in your program.

Presentation

Variables

Variables are containers that store information. You give them a name and assign a value using =.

world = '🌎🌍🌏'
python = 'Python 🐍'
fire = '🔥'
name = 'Shirley'
  • world stores emojis.
  • python stores text with an emoji.
  • fire stores a fire emoji.
  • name stores a string representing a name.

💡 Tip: Variables can store text (strings), numbers, or other types of data.

More Examples

name = "Alice"
age = 12
is_student = True
print(f"{name} {age}")

Changing Variable Values

You can update a variable by assigning it a new value:

score = 0
score = 10
print(score)  # 10

Using Variables in f-strings

f-strings let you insert variables directly into text:

name = "Alex"
print(f"Hello, {name}!")

This prints:

Hello, Alex!

Print / Output

print() shows information on the screen. It’s how you check what your code is doing.

print("This is output!")

Inputs

input() lets you get information from the user. It pauses the program and waits for the user to type something, which you can then store in a variable.

name = input("What is your name? ")
print(f"Nice to meet you, {name}!")
  • Whatever the user types is stored as text (a string) in the variable.
  • You can pass a prompt message inside input(...) to tell the user what to type.

💡 Tip: input() always treats what the user types as text, even if they type a number!

Typecasting

Because input() always returns text (a string), you need to convert it if you want to perform math with numbers. Converting data from one type to another is called typecasting.

  • int() converts a string into a whole number (integer).
  • float() converts a string into a decimal number.
  • str() converts a number back into a string.
age = int(input("How old are you? "))
print(f"Next year, you will be {age + 1} years old!")

Challenges

The Bible Character Greeter

Write a Python program that asks the user for their favorite Bible character using input() and prints a personalized greeting using f-strings.

Requirements:

  1. Prompt the user for their favorite Bible character and store it in a variable.
  2. Use an f-string to print a friendly greeting mentioning that character.

Expected Output (if user types “David”):

Who is you favourite Bible hero? David
That's awesome! David is a wonderful example of faith.

View Solution

# Bible character greeter
character = input("Who is you favourite Bible hero? ")
print(f"That's awesome! {character} is a wonderful example of faith.")

The Tithe Calculator

Based on the principle of giving in Malachi 3:10, write a program that asks the user for their weekly income using input(), typecasts it to a float, and calculates a 10% tithe.

Requirements:

  1. Prompt the user for their weekly income.
  2. Typecast the input string into a float value.
  3. Multiply the income by 0.1 to calculate the tithe.
  4. Print the final tithe amount using an f-string.

Expected Output (if user types “500”):

Enter your weekly income: 500
Your calculated tithe (10%) is: 50.0

View Solution

# Tithe calculator based on Malachi 3:10
income_str = input("Enter your weekly income: ")
income = float(income_str)
tithe = income * 0.1
print(f"Your calculated tithe (10%) is: {tithe}")

Bible Reading Progress Tracker

The entire Bible contains 1,189 chapters. Write an advanced script that prompts the user for how many chapters they have read, typecasts the input to an integer, calculates how many chapters are left, and computes their reading completion percentage.

Requirements:

  1. Prompt the user for the number of chapters they have read so far.
  2. Typecast the input into an integer.
  3. Calculate the remaining chapters out of 1189.
  4. Calculate the percentage completed rounded to 2 decimal places.
  5. Print a clear summary showing chapters read, chapters remaining, and percentage complete.

Expected Output (if user types “300”):

Chapters read: 300
Chapters remaining: 889
Progress: 25.23% complete!

View Solution

python copy # Bible reading progress tracker total_chapters = 1189 read_input = input("How many Bible chapters have you read? ") chapters_read = int(read_input) chapters_remaining = total_chapters - chapters_read percentage = (chapters_read / total_chapters) * 100 print(f"Chapters read: {chapters_read}") print(f"Chapters remaining: {chapters_remaining}") print(f"Progress: {percentage:.2f}\% complete!")
